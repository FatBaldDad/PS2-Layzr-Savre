# PS2-Layzr-Savre

**PS2-Layzr-Savre** is an **FBD / Fat Bald Dad** project focused on PlayStation 2 optical-drive preservation research, monitoring concepts, and future hardware-protection development.

The goal of this project is to better understand how PS2 optical-drive systems behave during normal use, failure conditions, and aging-related issues so original disc-reading hardware can be preserved, serviced, and protected more responsibly.

PS2-Layzr-Savre is being developed as a possible future FBD research platform, service tool, hardware project, or documented PlayStation 2 preservation effort.

> [!IMPORTANT]
> PS2-Layzr-Savre is currently in private development.
>
> This public repository exists to document the project name, public goals, development status, ownership, and safety position of the FBD PS2-Layzr-Savre project.
>
> This is **not** an open-source hardware, firmware, software, or manufacturing release at this time.
>
> Detailed PCB files, schematics, firmware, software tools, signal research, test data, manufacturing files, installation methods, hardware revision history, and internal development notes are intentionally private until the project is further tested and ready for release.

---

## Project Purpose

Many PlayStation 2 consoles are now old enough that optical-drive problems are becoming more common. Lasers, motors, ribbon cables, drive boards, and related components can age, fail, or behave unpredictably.

PS2-Layzr-Savre is intended to explore a careful and research-focused approach to understanding these issues.

The long-term goal is to help support preservation of original PS2 disc-reading hardware by studying drive behavior, collecting safe observations, and developing future tools or hardware that may assist with service, diagnostics, and protection.

## Safety Position

PS2-Layzr-Savre is an experimental research project.

It is **not** currently:

- A finished product
- A guaranteed laser-protection device
- A universal PS2 repair solution
- A beginner installation project
- A public installation guide
- A released hardware kit
- A released firmware or software package

Incorrect optical-drive modifications can damage hardware. No public installation method is currently provided.

Detailed safety validation remains private until the project is more mature.
